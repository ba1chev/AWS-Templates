# RDS module

Data tier: an RDS database (PostgreSQL or MySQL) in private subnets.

## What it creates

- DB subnet group
- RDS instance
  - Encrypted storage (gp3) with storage autoscaling
  - Not publicly accessible
  - Master password generated by RDS and stored in Secrets Manager, never in Terraform state
  - Automated backups (7 days), deletion protection, and a final snapshot by default
  - Logs exported to CloudWatch

## Usage

```hcl
module "db" {
  source = "../../modules/data/rds"

  name               = "dev-app-db"
  engine             = "postgres"
  subnet_ids         = module.vpc.private_subnet_ids
  security_group_ids = [module.db_sg.security_group_id]

  # dev: allow terraform destroy
  deletion_protection = false
  skip_final_snapshot = true
}
```

For prod, keep the defaults and set `multi_az = true`.

The application reads the password from the secret in `master_user_secret_arn`. Grant the EC2
role `secretsmanager:GetSecretValue` on that ARN.

## Inputs

| Name | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string` | — | DB identifier (lowercase, 1-63 chars) |
| `engine` | `string` | `"postgres"` | `postgres` or `mysql` |
| `engine_version` | `string` | `null` | Engine version; AWS default if null |
| `instance_class` | `string` | `"db.t4g.micro"` | Instance class |
| `allocated_storage` | `number` | `20` | Initial storage in GiB |
| `max_allocated_storage` | `number` | `100` | Storage autoscaling limit; 0 disables |
| `storage_type` | `string` | `"gp3"` | Storage type |
| `kms_key_id` | `string` | `null` | KMS key; AWS-managed key if null |
| `db_name` | `string` | `"app"` | Database name |
| `username` | `string` | `"dbadmin"` | Master username |
| `port` | `number` | `null` | Port; 5432 / 3306 if null |
| `subnet_ids` | `list(string)` | — | At least 2 private subnets |
| `security_group_ids` | `list(string)` | — | Security groups for the DB |
| `multi_az` | `bool` | `false` | Standby in another AZ (prod) |
| `backup_retention_period` | `number` | `7` | Backup retention in days |
| `backup_window` | `string` | `null` | Daily backup window (UTC) |
| `maintenance_window` | `string` | `null` | Weekly maintenance window (UTC) |
| `deletion_protection` | `bool` | `true` | Prevent deletion |
| `skip_final_snapshot` | `bool` | `false` | Skip the final snapshot on delete |
| `apply_immediately` | `bool` | `false` | Apply changes now instead of in the maintenance window |
| `performance_insights_enabled` | `bool` | `false` | Enable Performance Insights |
| `enabled_cloudwatch_logs_exports` | `list(string)` | `null` | Log exports; engine default if null |
| `tags` | `map(string)` | `{}` | Tags for all resources |

## Outputs

| Name | Description |
|------|-------------|
| `db_instance_identifier` | DB identifier |
| `db_instance_arn` | DB ARN |
| `endpoint` | `host:port` |
| `address` | Hostname |
| `port` | Port |
| `db_name` | Database name |
| `username` | Master username |
| `master_user_secret_arn` | Secrets Manager secret with the master password |
| `db_subnet_group_name` | DB subnet group name |
